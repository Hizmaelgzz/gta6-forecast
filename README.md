Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour (hours 2–24, five quantiles each), fitted at run time from the launch-day shapes of past big game launches. The shape depends on scale: huge launches are already near their peak in hour 1, small ones ramp several hundred-fold as unlocks roll across time zones, so the model conditions on the hour-1 print with a quadratic fit blended with nearest neighbours.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
